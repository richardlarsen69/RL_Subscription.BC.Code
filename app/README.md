# How to use this app template

## In GitHub

- Create template from template app https://github.com/Evidi-Optimise/App_Template_PTE, press use this template button.

## After creating a new repo

- Replace every placeholder in the repo with the appropriate value. Placeholders are marked with !!!
- To generate a new guid, you can use https://www.guidgen.com/
- If your app will not use pipelines, you may remove the .AL-Go and .github folders
- If your app will not use automated tests, you may remove the test folder, and the App.code-workspace file
